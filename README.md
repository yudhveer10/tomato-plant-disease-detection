# 🍅 Tomato Plant Disease Detection using CNN

A deep learning-based web app to detect various diseases in tomato plants using a Convolutional Neural Network (CNN). The model classifies the uploaded leaf image into different tomato disease categories and provides an easy-to-use interface via **Streamlit**.

---

## 📌 Features

- 🌿 Detects multiple tomato leaf diseases with high accuracy
- 🧠 Trained Convolutional Neural Network (CNN) model
- 🖼️ Upload image and get instant prediction
- 💻 Web-based GUI using Streamlit
- 🔁 Real-time inference

---

## 🚀 Tech Stack

- **Python 3**
- **TensorFlow / Keras** – for CNN model
- **OpenCV** – for image preprocessing
- **Streamlit** – for web app GUI
- **NumPy, Matplotlib** – for visualization and array handling

---

## 🧪 Dataset

- Publicly available **Tomato Leaf Disease dataset** from [PlantVillage Dataset](https://www.kaggle.com/emmarex/plantdisease).
- Includes both healthy and infected leaf images across various disease types (e.g., Early Blight, Late Blight, Septoria, etc.)

---

## 📊 Model Training

- CNN architecture with multiple convolutional, pooling, and dense layers
- Trained on augmented dataset for better generalization
- Achieved high training and validation accuracy
